# QCCommons Tracker

Simple local Vite React tracker for a 17-project QCCommons work session.

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints, usually `http://127.0.0.1:5173/`.

## Build check

```bash
npm run build
```

## What it tracks

- 17 editable QCCommons project rows
- project status, notes, and 90-minute block count
- 90/15 focus timer
- phone/TikTok/games guardrail checkboxes
- daily raw video checkbox
- local autosave in the browser via `localStorage`

No backend and no external posting.
